Rebuild it in RStudio

Or use one method below ↓
  1. Download and unzip

    Get the complete course folder. In RStudio, set the working directory to the extracted folder containing Course.Rmd.

  2. Install the dependencies once

    Run this in the R console. The installer checks the packages used by the course.

    source("install_dependencies.R")
  3. Open Course.Rmd and Knit

    Each knit uses the fixed seeds to recreate and save the datasets, runs the analyses, and builds the PowerPoint deck.

To refresh the instructor guide afterward, knit Instructor-dataset-guide.Rmd. Setup files: package installer · data builder · guide builder.
