# Pea flower opening time

Data file: `genetics-1.csv`

Each row is one plant from a separately raised pea family in a teaching greenhouse. Seed coat marker classes were recorded, not assigned.

Simulated data; 88 observations. No real people, specimens, or institutions are represented.

## Variables

- `first_flower_days`: Days from emergence to first open flower. Continuous response.
- `seed_width_mm`: Width of the planted seed (mm). Continuous predictor.
- `pot_rim_cm`: Measured internal pot diameter (cm). Continuous predictor.
- `marker_class`: Seed coat marker class. Categorical predictor. Levels: `m1`, `m2`.
- `leaf_length_cm`: Length of a fully expanded leaf (cm). Continuous predictor.
