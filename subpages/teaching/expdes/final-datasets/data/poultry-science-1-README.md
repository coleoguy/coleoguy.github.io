# Eggshell thickness in laying-hen housing

Data file: `poultry-science-1.csv`

Each row represents one simulated hen from a distinct recorded pen, represented by one egg. Housing type was observed, not assigned.

Simulated data; 81 observations. No real people, specimens, or institutions are represented.

## Variables

- `shell_thickness_mm`: Average shell thickness in millimeters across several positions on the same egg. Continuous response.
- `egg_mass_g`: Whole egg mass in grams. Continuous predictor.
- `nest_lining`: Nest surface observed in the housing unit. Categorical predictor. Levels: `fiber`, `rubber`.
- `nest_height_cm`: Height of the nest above the floor in centimeters. Continuous predictor.
- `collection_hour`: Local time of egg collection in decimal hours on a 24-hour clock. Continuous predictor.
