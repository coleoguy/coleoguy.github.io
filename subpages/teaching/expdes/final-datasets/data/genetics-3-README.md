# Bristle length in fruit flies

Data file: `genetics-3.csv`

Each record comes from one adult fly from an independently housed teaching-stock family. Eye marker classes are inherited and were observed rather than assigned.

Simulated data; 96 observations. No real people, specimens, or institutions are represented.

## Variables

- `bristle_length_um`: Length of a designated thoracic bristle (micrometers). Continuous response.
- `eye_marker`: Visible eye marker class. Categorical predictor. Levels: `amber`, `brick`.
- `wing_asymmetry_um`: Absolute difference in wing lengths (micrometers). Continuous predictor.
- `thorax_width_mm`: Maximum thorax width (mm). Continuous predictor.
- `imaging_temp_c`: Room temperature during imaging (degrees C). Continuous predictor.
