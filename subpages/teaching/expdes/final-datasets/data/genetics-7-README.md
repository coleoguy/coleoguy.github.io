# Shell banding in land snails

Data file: `genetics-7.csv`

One adult snail from each separate field patch was photographed. Shell morph and other characteristics were observed, not assigned.

Simulated data; 152 observations. No real people, specimens, or institutions are represented.

## Variables

- `band_present`: Whether a narrow dark band was visible on the final whorl (1 yes, 0 no). Binary response. 0 = criterion not met; 1 = criterion met.
- `aperture_tilt_deg`: Aperture angle in a standardized profile (degrees). Continuous predictor.
- `photo_temp_c`: Room temperature when photographed (degrees C). Continuous predictor.
- `shell_ground`: Ground color without the band. Categorical predictor. Levels: `pale`, `golden`, `brown`.
- `shell_width_mm`: Maximum adult shell width (mm). Continuous predictor.
