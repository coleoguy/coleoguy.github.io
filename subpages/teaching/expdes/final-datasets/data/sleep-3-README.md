# Nighttime movement in an observational sleep study

Data file: `sleep-3.csv`

Each of these fictional actigraphy summaries corresponds to a different simulated adult. Bedtime regularity and occupation schedule were recorded, not assigned.

Simulated data; 96 observations. No real people, specimens, or institutions are represented.

## Variables

- `sleep_fragmentation_index`: Device-derived dimensionless fragmentation score. Continuous response.
- `schedule_type`: Reported regular work pattern. Categorical predictor. Levels: `day`, `evening`, `variable`.
- `sync_delay_s`: Initial time synchronization delay, in seconds. Continuous predictor.
- `bedtime_variability_min`: Standard deviation of recent bedtimes, in minutes. Continuous predictor.
- `strap_mass_g`: Mass of the recording strap, in grams. Continuous predictor.
