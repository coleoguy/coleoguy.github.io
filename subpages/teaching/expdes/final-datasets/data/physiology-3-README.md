# Thermal preference in freshwater snails

Data file: `physiology-3.csv`

Each row corresponds to one snail presented once with an individually assigned choice arena. Arena liner was randomly assigned; snails were measured before the trial.

Simulated data; 136 observations. No real people, specimens, or institutions are represented.

## Variables

- `cool_side_selected`: Whether the snail was on the cool side at the scoring time. Binary response. 0 = criterion not met; 1 = criterion met.
- `camera_height_cm`: Height of the recording camera above the arena, in cm. Continuous predictor.
- `shell_length_mm`: Shell length at enrollment, in mm. Continuous predictor.
- `arena_width_cm`: Measured interior arena width, in cm. Continuous predictor.
- `liner_type`: Assigned arena liner. Categorical predictor. Levels: `smooth`, `textured`.
