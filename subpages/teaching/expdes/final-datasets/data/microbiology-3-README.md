# Pond diatom frustule width

Data file: `microbiology-3.csv`

One intact diatom frustule was measured in a microscope image from each independently sampled pond. Valve outline class was scored without assigning a treatment.

Simulated data; 76 observations. No real people, specimens, or institutions are represented.

## Variables

- `valve_width_um`: Maximum frustule width (micrometers). Continuous response.
- `pond_depth_m`: Depth where the sample was collected (m). Continuous predictor.
- `valve_outline`: Outline observed in the image. Categorical predictor. Levels: `linear`, `elliptical`, `lanceolate`.
- `valve_length_um`: End-to-end frustule length (micrometers). Continuous predictor.
- `surface_temp_c`: Surface water temperature at collection (degrees C). Continuous predictor.
