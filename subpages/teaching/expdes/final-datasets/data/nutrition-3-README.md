# Viscosity of fortified plant-based drinks

Data file: `nutrition-3.csv`

Each row is a distinct independently mixed sample from a simulated food-testing study. Base beverage category was allocated among batches and each batch was measured once.

Simulated data; 72 observations. No real people, specimens, or institutions are represented.

## Variables

- `viscosity_mpa_s`: Apparent viscosity at the standardized measurement in millipascal-seconds. Continuous response.
- `beverage_base`: Base assigned to the batch. Categorical predictor. Levels: `soy`, `oat`.
- `soluble_fiber_g_l`: Soluble dietary fiber concentration in grams per liter. Continuous predictor.
- `reading_delay_min`: Time from sample loading to the recorded reading in minutes. Continuous predictor.
- `container_diameter_mm`: Inside diameter of the sample container in millimeters. Continuous predictor.
