# Road-salt legacy in urban wetland soil

Data file: `toxicology-1.csv`

Each row represents one soil core from a different constructed wetland in a simulated monitoring survey; vegetation and chemistry were observed rather than assigned.

Simulated data; 64 observations. No real people, specimens, or institutions are represented.

## Variables

- `root_length_cm`: Mean root length in centimeters for a standardized non-food grass seedling screen of the core. Continuous response.
- `storage_hours`: Elapsed hours from field collection to sample logging. Continuous predictor.
- `core_diameter_cm`: Diameter of the intact core in centimeters. Continuous predictor.
- `chloride_mg_l`: Chloride concentration in the core water extract, milligrams per liter. Continuous predictor.
- `shoreline_cover`: Vegetation cover type at the sampling point. Categorical predictor. Levels: `turf`, `reeds`, `open`.
