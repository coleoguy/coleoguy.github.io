# Dragonfly wing flexibility

Data file: `entomology-5.csv`

Each row represents an adult dragonfly from a different pond. Individuals were grouped by observed wing pigmentation; the same non-destructive flex test was applied to every individual.

Simulated data; 96 observations. No real people, specimens, or institutions are represented.

## Variables

- `wing_deflection_mm`: Tip deflection under a standardized test load (mm). Continuous response.
- `wing_pattern`: Observed extent of dark wing pigmentation. Categorical predictor. Levels: `clear`, `banded`.
- `wing_length_mm`: Base-to-tip length of the tested wing (mm). Continuous predictor.
- `room_temp_c`: Air temperature during testing (degrees C). Continuous predictor.
- `body_mass_mg`: Body mass at testing (mg). Continuous predictor.
