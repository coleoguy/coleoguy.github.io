# Tomato color uniformity across breeding lines

Data file: `plant-breeding-4.csv`

Each row is one simulated greenhouse plant from a distinct tomato line. Support system was randomly assigned and the response summarizes a set of fruit images per plant.

Simulated data; 78 observations. No real people, specimens, or institutions are represented.

## Variables

- `color_variation_index`: Dimensionless between-fruit variation score based on image color values. Continuous response.
- `pot_volume_l`: Measured root-zone pot volume in liters. Continuous predictor.
- `support_system`: Support system assigned to the plant. Categorical predictor. Levels: `stake`, `cage`, `string`.
- `days_to_first_ripe`: Days from transplant to the first ripe fruit. Continuous predictor.
- `canopy_width_cm`: Canopy width at first bloom in centimeters. Continuous predictor.
