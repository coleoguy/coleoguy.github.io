# Restorative sleep and next-morning vigilance

Data file: `sleep-1.csv`

Each row is one simulated volunteer recorded on one night. Volunteers were randomly assigned to a test-order schedule, which determined when the vigilance task occurred within the morning session.

Simulated data; 105 observations. No real people, specimens, or institutions are represented.

## Variables

- `median_reaction_ms`: Median reaction time on the vigilance task, in milliseconds. Continuous response.
- `test_order`: Assigned position of the task in the morning schedule. Categorical predictor. Levels: `first`, `second`, `third`.
- `device_mass_g`: Mass of the wrist device, in grams. Continuous predictor.
- `screen_height_cm`: Height of the display center above the table, in cm. Continuous predictor.
- `sleep_efficiency_pct`: Percentage of time in bed scored as asleep. Continuous predictor.
