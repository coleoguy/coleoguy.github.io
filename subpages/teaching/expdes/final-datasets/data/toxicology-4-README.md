# Suspended sediment and freshwater leaf condition

Data file: `toxicology-4.csv`

Each row represents a different simulated observation pond and one randomly selected, independent sampling location per pond; shoreline features were not assigned.

Simulated data; 81 observations. No real people, specimens, or institutions are represented.

## Variables

- `yellow_leaf_pct`: Percentage of the sampled plant's leaf area judged yellow from images. Continuous response.
- `bank_profile`: Dominant physical bank shape at the sample site. Categorical predictor. Levels: `shallow`, `steep`.
- `suspended_solids_mg_l`: Suspended mineral solids in milligrams per liter. Continuous predictor.
- `water_depth_cm`: Water depth at sample point in centimeters. Continuous predictor.
- `sampling_duration_min`: Duration of the on-site collection in minutes. Continuous predictor.
