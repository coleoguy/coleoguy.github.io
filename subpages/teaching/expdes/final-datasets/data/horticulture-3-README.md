# Ornamental cutting establishment

Data file: `horticulture-3.csv`

Each row is one stem cutting taken from a distinct donor plant and individually potted. Bench-mat type was randomly assigned at the pot level in the simulated trial.

Simulated data; 132 observations. No real people, specimens, or institutions are represented.

## Variables

- `established`: Whether the cutting had both visible roots and a new leaf at assessment (1 = yes, 0 = no). Binary response. 0 = criterion not met; 1 = criterion met.
- `bench_mat`: Type of pad beneath the pot. Categorical predictor. Levels: `insulated`, `standard`.
- `pot_depth_cm`: Usable soil depth in the pot in centimeters. Continuous predictor.
- `stem_diameter_mm`: Initial mid-stem diameter in millimeters. Continuous predictor.
- `cutting_length_cm`: Initial cutting length in centimeters. Continuous predictor.
