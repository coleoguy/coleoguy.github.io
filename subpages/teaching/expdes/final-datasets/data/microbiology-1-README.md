# Yeast bud size under a classroom microscope

Data file: `microbiology-1.csv`

One budding cell per independent sample from separate lots of commercial baker's yeast was imaged for a classroom morphology survey. Parent cell shapes were recorded, not assigned.

Simulated data; 64 observations. No real people, specimens, or institutions are represented.

## Variables

- `bud_area_um2`: Projected area of the bud (square micrometers). Continuous response.
- `field_light_pct`: Recorded image brightness as a percent of instrument range. Continuous predictor.
- `parent_shape`: Observed parent-cell outline class. Categorical predictor. Levels: `round`, `oval`.
- `slide_temp_c`: Slide-stage temperature at imaging (degrees C). Continuous predictor.
- `parent_area_um2`: Projected area of the parent cell (square micrometers). Continuous predictor.
