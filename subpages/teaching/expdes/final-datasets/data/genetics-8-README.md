# Radish root shape

Data file: `genetics-8.csv`

Each record summarizes one harvested root from a separately grown radish family. Leaf color marker classes were observed.

Simulated data; 84 observations. No real people, specimens, or institutions are represented.

## Variables

- `shape_ratio`: Root length divided by maximum width (unitless). Continuous response.
- `leaf_marker`: Leaf pigmentation marker class. Categorical predictor. Levels: `pale`, `dark`.
- `root_crown_mm`: Width at the uppermost root crown (mm). Continuous predictor.
- `canopy_width_cm`: Canopy width before harvest (cm). Continuous predictor.
- `sowing_depth_mm`: Measured sowing depth (mm). Continuous predictor.
