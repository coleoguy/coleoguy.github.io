# Tomato fruit firmness

Data file: `genetics-5.csv`

One fruit was sampled from each independently raised tomato plant, with one plant per maternal line. Fruit color class was recorded, not assigned.

Simulated data; 76 observations. No real people, specimens, or institutions are represented.

## Variables

- `firmness_n`: Peak force in a standardized firmness measurement (N). Continuous response.
- `fresh_mass_g`: Fruit fresh mass (g). Continuous predictor.
- `stem_scar_mm`: Diameter of the stem scar (mm). Continuous predictor.
- `fruit_temp_c`: Surface temperature when measured (degrees C). Continuous predictor.
- `color_class`: Visible ripe fruit color class. Categorical predictor. Levels: `red`, `orange`, `yellow`.
