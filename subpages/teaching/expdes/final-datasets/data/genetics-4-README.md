# Barley awn phenotype

Data file: `genetics-4.csv`

One maternal line per record was represented by a single barley plant in a common garden. Marker class and plant traits were observed.

Simulated data; 165 observations. No real people, specimens, or institutions are represented.

## Variables

- `awns_present`: Whether the main spike was scored awned at maturity (1 awned, 0 awnless). Binary response. 0 = criterion not met; 1 = criterion met.
- `flag_leaf_angle_deg`: Flag leaf angle from vertical (degrees). Continuous predictor.
- `marker_class`: Observed marker class. Categorical predictor. Levels: `c1`, `c2`, `c3`.
- `stem_diameter_mm`: Stem diameter at a basal node (mm). Continuous predictor.
- `spike_length_cm`: Length of the main spike before maturity (cm). Continuous predictor.
