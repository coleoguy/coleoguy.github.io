# Clover leaflet marking

Data file: `genetics-6.csv`

Each clover plant came from a distinct maternal family grown in a teaching garden. Family marker class was measured, not assigned.

Simulated data; 132 observations. No real people, specimens, or institutions are represented.

## Variables

- `white_mark`: Whether a pale chevron was visible on the central leaflet (1 yes, 0 no). Binary response. 0 = criterion not met; 1 = criterion met.
- `marker_haplotype`: Observed marker haplotype. Categorical predictor. Levels: `h1`, `h2`.
- `moisture_pct`: Soil volumetric water content at scoring (percent). Continuous predictor.
- `leaflet_area_cm2`: Central leaflet area (square cm). Continuous predictor.
- `petiole_mm`: Petiole length (mm). Continuous predictor.
