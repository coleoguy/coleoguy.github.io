Phylogenetic Comparative Methods

A guide from first principles to working analyses
Closely related species are not independent observations — treat them as such and you will overstate evidence. Phylogenetic comparative methods correct for that shared history so you can test real evolutionary hypotheses about trait evolution, character correlation, and diversification.
Why this matters

Drop two squirrel species and a bat into the same scatter plot and the squirrels will sit near each other — not because of any process you care about, but simply because they share an ancestor. The data look like 3 points but contain perhaps 1.5 independent observations. Ordinary regression and correlation overstate evidence by treating shared ancestry as if it were replicated independent draws (the phylogenetic pseudoreplication problem; Felsenstein 1985). The methods below are the toolkit for doing it right.
